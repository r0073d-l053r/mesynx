These pages are about **using** Mesynx AI and apply whether you run the
hosted instance or your own. Operator concerns — install, environment
variables, storage, upgrades — live under
[Self hosting](../self-hosting).

## Getting recordings in

- **[Connect your Plaud account](./connect-plaud-account)** —
  email-and-code login, plus the Google/Apple workaround.

## Transcription and summaries

- **[AI providers](./ai-providers)** — wire up OpenAI, Groq, OpenRouter,
  Ollama, LM Studio, or anything else OpenAI-compatible, for both
  transcription and summarisation.
- **[Speakers and diarization](./speakers-and-diarization)** — separate
  who spoke when, and name each speaker once so the name appears
  everywhere, retroactively.
- **[Transcription workspace](./transcription-workspace)** — reshape a
  recording's summary into a tree you own, as a mind map, a force
  graph, or an outline, with the transcript evidence under every
  section.

## Getting data out

- **[Notifications](./notifications)** — Bark, browser, and email
  backends.
- **[Automation API and webhooks](./automation-and-webhooks)** —
  personal API keys and signed webhook deliveries.
- **[Backup and restore](./backup-and-restore)** — export every
  recording, transcript, and audio file so you can leave.
