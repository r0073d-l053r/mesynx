Mesynx AI is an open-source companion app for AI voice recorders. Sign
up at the hosted instance for the hosted instance, or
run the same codebase on your own infrastructure with Docker Compose.
Bring any OpenAI-compatible API key, keep your recordings, leave
whenever you want.

Currently supports the Plaud Note family — Note, Note Pro, and
NotePin. More device support is on the way.

## For everyone

These guides apply whether you're on hosted or self-host — they're
about using Mesynx AI as a product.

- **[Connect your Plaud account](/docs/guides/connect-plaud-account)** —
  email-and-code login, plus the Google/Apple workaround.
- **[AI providers](/docs/guides/ai-providers)** — wire up OpenAI, Groq,
  OpenRouter, Ollama, LM Studio, or anything else OpenAI-compatible.
- **[Speakers and diarization](/docs/guides/speakers-and-diarization)** —
  separate who said what, and name each speaker once so it appears
  everywhere.
- **[Transcription workspace](/docs/guides/transcription-workspace)** —
  reshape a summary into a tree you own: mind map, force graph, or
  outline.
- **[Notifications](/docs/guides/notifications)** — Bark, browser, and
  email backends.
- **[Automation API and webhooks](/docs/guides/automation-and-webhooks)** —
  personal API keys and signed webhook deliveries.
- **[Backup and restore](/docs/guides/backup-and-restore)** — export
  every recording, transcript, and audio file so you can leave.

## How it ships

Mesynx AI is AGPL-3.0 software. The hosted instance is
multi-tenant SaaS we operate; self-host deployments run the same image
under your control. Both modes are first-class.
